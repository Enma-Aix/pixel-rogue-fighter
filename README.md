# 烬途

一款浏览器里的横版像素肉鸽格斗。一局是一张岔路：战斗、精锐、商店、际遇和歇脚。夜郊、竹影、残城各以一位首领收束：灯魂、竹客、残将。强化分成灼血、迅刃、反手、奥流，同路拿得越多越会咬合。这一局的金币能在路摊花掉，剩下的在结算时存进永久强化。

画面是程序绘制的像素角色，不使用外部付费素材。界面字体为 [ZCOOL KuaiLe](https://fonts.google.com/specimen/ZCOOL+KuaiLe)（SIL Open Font License，见 `src/assets/OFL-ZCOOLKuaiLe.txt`）。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。生产构建：

```bash
npm run build
npm run preview
```

`npm run build` 会先做类型检查，再把静态站点输出到 `dist/`。`vite.config.ts` 里 `base` 为 `./`，可以直接用静态服务器打开，也可以放到 GitHub Pages。

## 怎么玩

1. 在标题选「开始征途」，先看到这一局的岔路。能走的房间会亮着，左右或点击进入。
2. 战斗和精锐是一间短的横版战场。三折各有自己的颜色、远景和危险。清完走进出口，三选一强化。
3. 敌人除了步卒、弓手、重甲，还有举盾的盾卫、扔炸弹的火师、扑过来的影刺。精锐会带甲、狂怒或分裂，金币更多。
4. 商店用这一局的金币买强化或疗伤。际遇是二选一的岔事。歇脚可以回血，或花 16 金换一张普通强化。
5. 强化有普通、稀有、珍品。灼血管流血和点燃，迅刃管暴击和速度，反手管闪避后的反击，奥流管奥义。同一路攒到 2 层、4 层会有额外效果。
6. 每折尽头是一位首领。灯魂扔灯、扑击、铺鬼火；竹客突刺、连镖、半血后瞬步；残将横斩、突进、弧月，半血后震地和连斩。出手前会亮招式名，打完会停一下。前两位倒下后仍可挑一张强化；打倒残将即破阵。生命归零则本局结束。
7. 结算时，身上还没花掉的金币存进浏览器本地。标题里的「永久强化」可以买体质、力量、身法、奥义和财运。一次购买就能感到差别，后面的等级会越来越贵。

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | `A` / `D` 或 `←` / `→` |
| 跳跃 | `W`、空格或 `↑`。点按跳得矮，按住跳得高 |
| 轻击 | `J` |
| 重击 | `K` |
| 闪避 | `L` 或 `Shift`。闪避中有短暂无敌 |
| 奥义 | `U`。有冷却 |
| 连招 | `J` → `J` → `K` |
| 暂停 | `Esc` |
| 音量 | `M`（关 / 低 / 中 / 高）。各折有一段循环的程序生成曲 |
| 菜单 | `↑` `↓` 选择，`Enter` 确认 |

触屏设备会在画面下沿两侧出现「左 右 跳 轻 重 闪 奥」，中间留出战场。桌面默认不显示，暂停里可以打开「触屏按键」。

## 部署到 GitHub Pages

仓库里有 `.github/workflows/pages.yml`。推到 `main` 后，到仓库 Settings → Pages，把 Source 设为 GitHub Actions。动作跑完后，站点地址会出现在该次运行的环境网址里。

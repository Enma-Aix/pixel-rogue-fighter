# 烬途

一款浏览器里的横版像素肉鸽格斗。一局是一张岔路：战斗、精锐、商店、际遇和歇脚。夜郊、竹影、残城各以一位首领收束：灯魂、竹客、残将。强化分成灼血、迅刃、反手、奥流，同路拿得越多越会咬合。这一局的金币能在路摊花掉，剩下的在结算时存进永久强化。

第一次点「开始征途」会先进一间短教学，教走路、轻击、连招、闪避和奥义。Esc 或右上角「跳过」可以直接上路。教学进度记在本地，之后不会再强制出现，设置里可以「再看教学」。

画面是程序绘制的像素角色，不使用外部付费素材。界面字体为 [ZCOOL KuaiLe](https://fonts.google.com/specimen/ZCOOL+KuaiLe)（SIL Open Font License，见 `src/assets/OFL-ZCOOLKuaiLe.txt`）。

## 功能

- 三折岔路。每折尽头固定是首领：灯魂、竹客、残将。招式出手前会亮名字，半血会换阶段。
- 步卒、弓手、重甲，以及盾卫、火师、影刺。精锐会带甲、狂怒或分裂。
- 强化有普通、稀有、珍品，四条路各自咬合。
- 本局金币用于路摊；结算时剩下的金币进入永久强化（体质、力量、身法、奥义、财运）。
- 设置里分开调节音乐和音效，开关屏幕震动，选择触屏按键，改键，或重置金币、强化和战绩。
- 触屏按键贴在画面下沿两侧，中间留给战场。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。生产构建：

```bash
npm run build
npm run preview
```

`npm run build` 会先做类型检查，再把静态站点输出到 `dist/`。本地构建的 `base` 是 `./`，用 `npm run preview` 或任意静态服务器都能打开。

2. 在 Build and deployment 里把 Source 选成 GitHub Actions。

5. 打开 Actions，等 “Deploy GitHub Pages” 成功。

工作流在构建时设置 `VITE_BASE=/pixel-rogue-fighter/`，资源会从项目页路径加载。本地的 `npm run build` 不会带这个前缀。

## 怎么玩

1. 标题选「开始征途」。第一次会进教学室，对着木人走完五步，或按 Esc 跳过。
2. 接着看到这一局的岔路。能走的房间会亮着，左右或点击进入。
3. 战斗和精锐是一间短的横版战场。三折各有自己的颜色、远景和危险。清完走进出口，三选一强化。
4. 商店用这一局的金币买强化或疗伤。际遇是二选一的岔事。歇脚可以回血，或花 16 金换一张普通强化。
5. 每折尽头是一位首领。灯魂扔灯、扑击、铺鬼火；竹客突刺、连镖、半血后瞬步；残将横斩、突进、弧月，半血后震地和连斩。前两位倒下后仍可挑一张强化；打倒残将即破阵。生命归零则本局结束。
6. 结算时，身上还没花掉的金币存进浏览器本地。标题里的「永久强化」可以买下一次开局就生效的属性。
7. 「设置」可以调音乐、音效、震屏、触屏和按键。重置存档会清空金币、永久强化、战绩和教学进度，音量和按键保留。

## 操作

| 动作 | 默认按键 |
| --- | --- |
| 移动 | `A` / `D`，方向键也能走 |
| 跳跃 | `W`、空格或 `↑`。点按跳得矮，按住跳得高 |
| 轻击 | `J` |
| 重击 | `K` |
| 闪避 | `L` 或 `Shift`。闪避中有短暂无敌 |
| 奥义 | `U`。有冷却 |
| 连招 | `J` → `J` → `K`（站在地上） |
| 暂停 | `Esc` |
| 音效 | `M`（关 / 低 / 中 / 高）。音乐在设置里单独调 |
| 菜单 | `↑` `↓` 选择，`Enter` 确认。设置里也可以用左右改数值 |

字母键可以在「设置 → 按键设置」里改。方向键、空格和 Shift 始终还能用。`M`、`Esc` 和 `Enter` 留给音效和菜单。

触屏设备会在画面下沿两侧出现「左 右 跳」和「轻 重 闪 奥」，中间留出战场。桌面默认不显示。暂停或设置里可以把触屏按键设成开、关，或跟随设备自动判断。

各折有一段循环的程序生成曲。音效和音乐分开记在本地，关掉音效不会把音乐一起关掉。屏幕震动也可以单独关掉。
